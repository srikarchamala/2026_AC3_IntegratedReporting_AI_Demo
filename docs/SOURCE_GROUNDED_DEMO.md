# No-code integrated reporting demo

The current demonstration uses manually uploaded skills, reports, and online references in ChatGPT or Claude.

Start with the [complete upload kit](../manual_demo/AC3_No_Code_Demo_Kit.zip) and the [click-by-click presenter guide](../manual_demo/START_HERE.md). Extract the outer kit, then upload its inner `integrated-reporting-demo.zip` through the app's Skills interface. A self-contained ChatGPT Project option is included.

Compare two fresh conversations in the same app and model: a regular request with the four reports, followed by the saved workflow with those reports. Show source evidence, the guideline actually consulted, criteria assessment, the draft, and review concerns.

See [design notes](ARCHITECTURE.md) for the distinction between a saved workflow, independent agents, and review. All results are synthetic teaching drafts.
